Optional: Ruffle, the Flash player that shows the game's Flash movies.

Download Ruffle's "self-hosted" web build from https://ruffle.rs/downloads and unpack it here, so that this folder
contains ruffle.js and Ruffle's two .wasm files (ruffle.js.map is not needed).  Keep Ruffle's licence files with it.
Tested with Ruffle 0.8.0.  Without it the game skips its Flash movies.  See ../README.md, section 4.
